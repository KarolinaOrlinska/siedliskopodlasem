# siedliskopodlasem
Agroturystyka w sercu Roztocza (woj. lubelskie) mająca w swojej ofercie przytulne domki na wynajem w otoczeniu lasu. 

## Jak zbudowana jest strona
- `index.html` – cała treść strony (teksty, sekcje, formularz)
- `css/style.css` – wygląd (kolory na samej górze pliku)
- `js/main.js` – menu na telefonie, wysyłanie formularza, galeria
- `images/` – logo i zdjęcia

Miejsca do uzupełnienia są oznaczone w treści jako `[DO UZUPEŁNIENIA]`.
Formularz wysyła wiadomości przez Web3Forms na adres siedliskopodlasem98@gmail.com.

## Gałęzie
- `main` – prawdziwa strona (Vercel)
- `test` – podgląd zmian przed publikacją
